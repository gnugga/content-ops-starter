# QuizCast (working title)

A Bezzerwizzer-style trivia party game for phones. One player's phone **hosts** the room and
**casts the board and questions to a TV** (Apple TV / AirPlay, Chromecast, smart-TV browser).
The host keeps playing on their phone like everyone else: the TV shows the shared stuff, and each
phone shows that player's private hand, bets and answers.

Status: **concept / docs only**. No code yet. See [HANDOFF.md](HANDOFF.md).
